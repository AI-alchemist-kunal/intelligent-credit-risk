
# Intelligent Credit Risk Assessment & Loan Underwriting

An end-to-end machine learning project that predicts
borrower repayment difficulty and investigates how
risk estimates can support responsible lending decisions.

## Business Objective

Develop predictive models using historical loan
application data to estimate repayment risk and
evaluate illustrative underwriting policies.

## Dataset

Home Credit Default Risk (Kaggle).

The model predicts the competition-defined repayment
difficulty target. It is not a regulatory default model.

## Planned Methodology

1. Exploratory Data Analysis
2. Data Cleaning and Feature Engineering
3. Logistic Regression Baseline
4. XGBoost / LightGBM Comparison
5. Model Evaluation and Calibration
6. Explainability
7. Underwriting Decision Simulation
8. Optional API and Dashboard

## Limitations

This is an educational project, not a production
credit approval system. It uses public historical
data and has limitations regarding temporal
validation, selection bias and lending economics.
